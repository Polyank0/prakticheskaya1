# Эмулятор оболочки ОС. Вариант №27

Практическая работа №1 по дисциплине «Конфигурационное управление».

Готовность: этап 1 из 5 (REPL).

## Общее описание

Программа имитирует командную строку UNIX-подобной ОС в графическом окне.
Ввод и вывод идут в одном текстовом поле, как в настоящем терминале:
после приглашения набирается команда, по Enter она выполняется.

- графический интерфейс на Tkinter, сторонние пакеты не нужны;
- имя VFS выводится в заголовке окна и в приглашении;
- аргументы в кавычках, комментарии после `#`;
- раскрытие переменных окружения реальной ОС: `$NAME`, `${NAME}` (в Windows также `%NAME%`);
- команды `ls` и `cd` пока заглушки: выводят своё имя и аргументы;
- сообщения об ошибках выделяются красным цветом.

## Функции и настройки

### Команды

| Команда | Действие |
|---|---|
| `ls [аргументы]` | заглушка: выводит имя и аргументы |
| `cd [аргументы]` | заглушка: выводит имя и аргументы |
| `exit` | завершение работы |

### Модули

| Файл | Назначение |
|---|---|
| `src/app.py` | точка входа |
| `src/terminal_window.py` | окно терминала |
| `src/session.py` | состояние сеанса и выполнение строк |
| `src/lexer.py` | разбор строки и раскрытие переменных |
| `src/errors.py` | исключения |
| `src/commands/` | команды и их реестр |

## Сборка и запуск тестов

Сборка не нужна. Требуется Python 3.9 или новее с модулем Tkinter
(входит в стандартный установщик Python для Windows).

```bat
rem запуск эмулятора
run.bat

rem модульные тесты
test.bat
```

Без bat-файлов те же действия выполняются так:

```
python -m src.app
python -m unittest discover -s tests -t . -v
```
