# Эмулятор оболочки ОС. Вариант №27

Практическая работа №1 по дисциплине «Конфигурационное управление».

Готовность: этап 5 из 5 (дополнительные команды).

## Общее описание

Программа имитирует командную строку UNIX-подобной ОС в графическом окне.
Ввод и вывод идут в одном текстовом поле, как в настоящем терминале:
после приглашения набирается команда, по Enter она выполняется.
Файлы и каталоги берутся из виртуальной файловой системы (VFS),
которая загружается из CSV-файла и живёт только в оперативной памяти.

- графический интерфейс на Tkinter, сторонние пакеты не нужны;
- имя VFS выводится в заголовке окна и в приглашении;
- аргументы в кавычках, комментарии после `#`;
- раскрытие переменных окружения реальной ОС: `$NAME`, `${NAME}` (в Windows также `%NAME%`);
- параметры командной строки и отладочный вывод параметров при запуске;
- стартовый скрипт: на экране видны и команды, и ответы;
- VFS из CSV-файла, содержимое файлов хранится в base64;
- история команд: команда `history`, клавиши «вверх» и «вниз»;
- копирование файлов и каталогов внутри VFS без записи на диск;
- сообщения об ошибках выделяются красным цветом.

## Функции и настройки

### Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--vfs ПУТЬ` | путь к CSV-файлу с VFS |
| `--script ПУТЬ` | путь к стартовому скрипту |

Оба параметра необязательны. Все заданные параметры печатаются
в окне при запуске строками вида `[debug] ключ=значение`.

### Стартовый скрипт

Текстовый файл, по одной команде в строке. Строка, начинающаяся с `#`,
считается комментарием, как в Python. Команды выполняются по очереди,
ошибка в одной команде не останавливает скрипт.

### Команды

| Команда | Действие |
|---|---|
| `ls [-l] [путь...]` | содержимое каталогов; `-l` добавляет тип и размер |
| `cd [путь]` | смена текущего каталога; без аргумента переход в `/` |
| `cat ФАЙЛ...` | вывод содержимого файлов |
| `tail [-n ЧИСЛО] ФАЙЛ...` | последние строки файлов, по умолчанию 10 |
| `history [ЧИСЛО]` | список введённых команд или последние ЧИСЛО команд |
| `history -c` | очистка истории |
| `cp ИСТОЧНИК... ЦЕЛЬ` | копирование файлов в памяти |
| `cp -r ИСТОЧНИК... ЦЕЛЬ` | копирование каталогов вместе с содержимым |
| `conf-dump` | параметры эмулятора в формате `ключ=значение` |
| `vfs-info` | служебная команда: источник и дерево VFS |
| `exit` | завершение работы |

### Формат VFS

CSV-файл с заголовком `path,type,data`:

| Столбец | Значение |
|---|---|
| `path` | абсолютный путь элемента, например `/docs/a.txt` |
| `type` | `dir` для каталога, `file` для файла |
| `data` | содержимое файла в base64; у каталога пусто |

Вложенность задаётся полным путём. Недостающие родительские каталоги
создаются автоматически. Исходный CSV-файл программа не изменяет.

```csv
path,type,data
/docs,dir,
/docs/hello.txt,file,SGVsbG8K
```

Готовые примеры лежат в каталоге `vfs/`: `minimal.csv` (один файл),
`several.csv` (несколько файлов), `deep.csv` (три уровня вложенности),
`broken.csv` (файл с ошибкой).

### Модули

| Файл | Назначение |
|---|---|
| `src/app.py` | точка входа |
| `src/terminal_window.py` | окно терминала |
| `src/session.py` | состояние сеанса и выполнение строк |
| `src/lexer.py` | разбор строки и раскрытие переменных |
| `src/errors.py` | исключения |
| `src/commands/` | команды и их реестр |
| `src/settings.py` | параметры командной строки |

## Сборка и запуск тестов

Сборка не нужна. Требуется Python 3.9 или новее с модулем Tkinter
(входит в стандартный установщик Python для Windows).

```bat
rem запуск эмулятора
run.bat --vfs vfs\several.csv --script startup\stage5.txt

rem модульные тесты
test.bat
```

Без bat-файлов те же действия выполняются так:

```
python -m src.app
python -m unittest discover -s tests -t . -v
```

Скрипты реальной ОС, которые запускают эмулятор с разными параметрами:

- `os_tests\params.bat` — все сочетания параметров командной строки;
- `os_tests\params_errors.bat` — неверные пути в параметрах;
- `os_tests\vfs_variants.bat` — минимальная VFS, несколько файлов, три уровня;
- `os_tests\vfs_errors.bat` — отсутствующий и испорченный файл VFS;
- `os_tests\commands.bat` — стартовые скрипты этапов с командами.

Каждый вызов открывает окно. Следующий вызов начинается после закрытия окна.

Стартовые скрипты для проверки команд: `startup/stage2.txt`, `startup/stage3.txt`, `startup/stage4.txt`, `startup/stage5.txt`.

## Примеры использования

```
several:/$ ls -l
d       - docs
d       - empty
f      19 readme.txt
several:/$ cd docs
several:/docs$ cat todo.txt
buy milk
sleep
several:/docs$ tail -n 1 notes.txt
third line
several:/docs$ cat nothing.txt
cat: nothing.txt: No such file or directory
several:/docs$ history 2
    5  cat nothing.txt
    6  history 2
several:/docs$ cp todo.txt /todo_copy.txt
several:/docs$ cp -r /docs /backup
several:/docs$ ls /
backup/
docs/
empty/
readme.txt
todo_copy.txt
several:/docs$ cp /docs /again
cp: -r not specified; omitting directory '/docs'
```

Запуск с параметрами:

```bat
run.bat --script startup\stage2.txt
run.bat --vfs vfs\deep.csv
```
